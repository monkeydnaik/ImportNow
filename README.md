# ImportNow

A responsive React website concept for a China-to-India sourcing and logistics service.

## Stack
- React 18
- Vite
- Tailwind CSS
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy
Import this GitHub repository into Vercel. Use the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

## Important demo limitations
The corridor animation and shipment status are illustrative UI demonstrations, not live carrier integrations. The landed-cost estimator uses sample assumptions and is not a customs quote or tax determination. The enquiry form should be connected to a secure backend or CRM before collecting real customer data. Business claims and service metrics in the concept should be verified by the actual operator before publication.
